# A hawkish / dovish lexicon for FOMC statement language.
#
# METHOD, AND WHAT IS AND IS NOT BORROWED
# ---------------------------------------
# The *construction* is Apel & Blix Grimaldi's: a central-bank sentence is not
# scored by counting loaded words, it is scored by pairing a DIRECTION word with
# an OBJECT word inside a short window. "inflation" alone says nothing -- it is
# in every statement ever written. "inflation has moderated" and "inflation has
# picked up" say opposite things, and only the pair carries the sign.
#
#   Apel, M. and Blix Grimaldi, M. (2012), "The information content of central
#   bank minutes", Sveriges Riksbank Working Paper Series No. 261.
#   https://www.riksbank.se/en-gb/press-and-published/publications/working-paper-series/
#
# The *terms below are not a reproduction of that paper's appendix*, and this
# file does not pretend they are. They are the direction and object vocabulary
# the FOMC actually uses, read off the statement corpus this package fetches
# (246 statements, 1994-2026). Saying otherwise would be a citation that cannot
# be checked, which is the thing this repo exists not to do.
#
# THE INVERSION THAT MOST LEXICONS GET WRONG
# ------------------------------------------
# Slack is signed the other way. "inflation rose" is hawkish; "unemployment
# rose" is dovish. A flat object list scores both as hawkish and is then
# systematically wrong about every labour-market sentence in a cutting cycle --
# which is exactly the sentence that matters. [object.slack] carries the flip.
#
# SCORING
# -------
#   hawkish hit = up-word   within WINDOW tokens of a price/activity object
#               | down-word within WINDOW tokens of a slack object
#               | up-word   within WINDOW tokens of a policy object
#   dovish  hit = the mirror of each.
# WINDOW is set in lexicon.py, not here, so this file stays pure data.
#
# NEGATION is handled in lexicon.py by flipping a hit when a negator ("not",
# "no", "little", "unlikely") sits between the direction word and the object.
#
# READ THE COVERAGE NOTE BEFORE USING THE OUTPUT. The score is reported with
# what it is actually worth measured against the decision, and the measurement
# is not flattering.
